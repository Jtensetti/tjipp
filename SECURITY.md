# Säkerhet

Rapportera sårbarheter till [Jonatan@tensetti.se](mailto:Jonatan@tensetti.se).
Ange berörd revision, förutsättningar och reproduktion. Skicka inte pass, persondata,
sessionsvärden eller privata nycklar. Be om en säker överföringsväg för känsliga bilagor.

Använd syntetiska identiteter i automatiska tester. Tillgänglighet och svarstid
garanteras inte. Materialet innebär inget myndighetsgodkännande.
